## Adaptive Calibration Completion Evidence (ML-04)

**Method and data audit**

- The implementation follows Brown and Russell's AC-Linear method from [arXiv 2606.04469](https://arxiv.org/abs/2606.04469): the symmetric pair-location feature is `(z1 + z2) / ||z1 + z2||`, concatenated with raw cosine and fit by L2 logistic regression with `C=0.1`. Training uses scikit-learn; inference is a small validated NumPy dot product.
- Adaptive promotion requires at least 80 contextual labels and 20 per class, an identity-disjoint split, more than `0.001` held-out Brier gain over the live fused-score Platt fallback, no ranking regression, and no material pose/media/age-gap Brier regression. Failure, sparse context, invalid weights, missing context, or model drift explicitly falls back through per-person Platt, global Platt, then raw-score queue ordering.
- This is group-label-free local/operational calibration. The gate intentionally uses pose, media kind, and derived age-gap bands, not inferred protected traits; it does not establish demographic fairness.
- The fixed cohort contains 60 model-specific vectors generated from a pinned Syn-Vis-v0 sample. Source images are CC0-1.0; curation/docs are CC-BY-SA-4.0. Images are not shipped. The manifest records source revision `100262732989e77f38cd831d70a376a93735006a`, every source hash, selection counts, recognizer hashes, and the source's female-presenting/~30/beauty-symmetry limitations.

**Implementation audit**

- `crossage_fr/match/calibration.py` provides guarded symmetric pair centers, true two-sided AS-Norm, strict AC-Linear payload validation, fitting, Brier/ECE/log-loss metrics, and identity-held-out operational-slice promotion gates.

- `models/cohort` ships immutable 60x512 float32 packs for antelopev2 and buffalo_l. `crossage_fr/match/cohort.py` verifies manifest/vector/model/source/license pins, shape, dtype, finiteness, and unit norms with pickle disabled; unsupported, absent, or corrupted packs fail closed.

- Live scans compute symmetric probe/reference AS-Norm against the fixed cohort and use it only as a precision guard on `confident` decisions; the existing enrolled-other-person cohort remains additive. Pair center, cohort z-score, model, reference, and cohort version are stored for subsequent human labels.

- SQLite schema 7 stores pair context as a bounded normalized 512-float BLOB plus media/pose/age evidence. Reference/model mismatches, deletion, replacement, reassignment, high-detail recheck, and correction undo all invalidate or restore context atomically.

- Candidates persist calibrated probability, source, and artifact-version hash. Creation, queue refresh, staged promotion, personalized calibration, rollback, and high-detail verification all use the same adaptive-to-Platt resolution order; bulk context reads avoid per-candidate connection churn.

- Calibration artifacts are versioned `calibration-adaptive-fmr-v2`, contain rollback metadata and explicit fallback status, reject dimension/model/non-finite/non-monotonic drift, and refit the promoted adaptive model on all eligible labels only after held-out promotion.

- The backend build independently pins the cohort manifest and both vector files, packages them into PyInstaller, and Electron also includes the directory for source fallback. Runtime, model-integrity, and installer diagnostics report cohort verification with redacted paths. `THIRD_PARTY_NOTICES.md` carries source/license attribution.

**Verification audit**

- `tests/adaptive_calibration_units.py` covers pair symmetry, true two-sided normalization, regional probability, score monotonicity, sparse/tampered/model-mismatched fallback, live queue provenance, reassignment invalidation, config corruption, operational slices, a 4,000-row held-out gain gate, and end-to-end 512-dimensional artifact promotion/application.

- `tests/cohort_units.py`, `tests/calibration_units.py`, and `tests/scoring_units.py` cover offline real-pack load, model routing, manifest/vector tampering, DB round trips and corrupt BLOBs, replacement/undo lifecycle, explicit fallback, and the precision-only band guard. Learning-loop, desktop packaging, coverage-contract, and the direct operational API scenario pass.

- `npm run bench:adaptive-calibration` ran `glintr100` plus the verified cohort over 224 prepared public-fixture images.
