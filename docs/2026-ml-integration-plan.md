# 2026 On-Device ML/Media Integration Plan (open-source, offline, 99.9th-percentile)

Deep-research-backed plan to integrate best-in-class open-source models for every external residual of the Apple Photos local-gap backlog. All picks are **ONNX / onnxruntime-CPU**, run **fully offline** (weights vendored at build time, never fetched on-device — satisfying `noNetworkIntelligence` + socket-blocking tests), and carry **permissive licenses**.

> Status legend: **INTEGRATED** = working offline today; **ACTIVATE** = code/seam ready (or trivially addable), needs a one-time weight/pip fetch on an online build machine; **N/A here** = blocked by the offline sandbox (no network) — run the install on an online host.

## Integration status (updated 2026-06-30, after network was enabled)

Validated end-to-end with the **actual open-source weights** running locally on onnxruntime-CPU, fully offline (socket-blocked tests). Each engine mirrors the `crossage_fr/ingest/safety.py` seam (disk discovery, lru session, in-code SHA-256 pin, graceful degradation); weights are vendored under `models/<role>/` (gitignored, `README.md` per pack with source URL + sha256), runtime deps pinned in `requirements*.txt`.

## Already integrated offline (verified on disk)
- **Face detection/recognition** — InsightFace SCRFD + ArcFace ONNX packs (`~/.insightface/models/buffalo_l`, `antelopev2`) via onnxruntime. (Optional upgrade below: LVFace.)
- **Sensitive-content** — bundled NSFW ViT INT8 ONNX (`models/safety/adamcodd_vit_base_nsfw_int8.onnx`) via onnxruntime.
- **RAW decode** — `rawpy` 0.27 / LibRaw 0.22, now tuned to **DHT demosaic + explicit sRGB** for 99.9th-percentile color fidelity (`crossage_fr/ingest/image_io.py::_raw_postprocess_kwargs`, graceful fallback). Covered by `tests/photo_raw_fidelity_units.py`.
- **Video / Memory movies** — `imageio_ffmpeg` bundles the ffmpeg binary; `export_photo_memory_movie` + video frame/preview rendering run offline.
- **Runtime** — ONNX Runtime CPU already installed; the whole plan rides on it.
